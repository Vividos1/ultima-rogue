# Ultima Rogue — The Forgotten Depths

An offline, seeded roguelike inspired by classic Ultima Online interactions and original Rogue dungeon exploration.

## v0.2 exploration prototype

- Avatar begins in an unlocked prison cell with randomly generated starter gear inside skeletal remains.
- Seeded rooms and corridors; stairs, containers, loot, doors, mouse click-to-walk and right-mouse steering.
- Skill design: whole-number skills, up to 100 per skill, and a 700-point total skill cap.
- Combat, animated movement, saves and real skill gains are upcoming work.

## Running

Open `index.html` in a browser after copying the local `assets/` PNG images from the v0.2 demo to this folder. The UO artwork is not included in the GitHub repository pending verification of redistribution rights.

## Asset rights

RunUO's open-source server code does **not** automatically grant redistribution rights to Ultima Online's original client artwork. Keep a legally obtained local set of the extracted sprites in `assets/`; these files are ignored by Git.
